# NEXTGEN Agency Template

A premium, modern one-page agency portfolio template built for the modern web. This theme features a beautiful dark mode aesthetic with glassmorphism design patterns, a responsive portfolio grid, interactive animations, and a professional layout to showcase services and projects.

## Features

- Fully responsive layout
- Premium modern dark aesthetic
- Glassmorphism design elements
- IntersectionObserver animations
- Custom cursor & dynamic scroll
- Portfolio grid with modals

## Usage

### Development

To start the development server:

```bash
npm install
npm start
```

### Production Build

To build the project for production:

```bash
npm run build
```
